# PIMX · پورتفولیوی شخصی

من محمدرضا عابدین‌پور هستم، برنامه‌نویس ساکن رشت. از سال ۲۰۲۱ برنامه‌نویسی می‌کنم و با پایتون، جنگو، رابط‌های وب، ربات‌های تلگرام و ابزارهای هوش مصنوعی کار می‌کنم. این سایت پروژه‌ها، لینک سورس، گواهی‌نامه‌ها و رزومه‌ام را در یک جا جمع می‌کند.

صفحهٔ اصلی شش پروژهٔ منتخب را نمایش می‌دهد؛ فهرست پروژه‌ها مجموعهٔ کامل‌تری با جست‌وجو، جزئیات فنی و لینک‌های مرتبط دارد. پیش‌نمایش محصولات از رابط واقعی آن‌هاست و توضیحات کوتاه، کاربرد هر ابزار را بیان می‌کنند.

## اجرای محلی

به **Node.js نسخهٔ 22.12 یا جدیدتر** و npm نیاز دارید. فایل قفل وابستگی‌ها در مخزن موجود است.

<div dir="ltr">

```bash
git clone https://github.com/MOHAMMADREZAABEDINPOOR/pimxportfolio.git
cd pimxportfolio
npm ci
npm run dev
```

</div>

سایت در **http://localhost:3000** اجرا می‌شود. متغیر `PORT` پورت را تغییر می‌دهد.

| دستور | کاربرد |
| --- | --- |
| `npm run dev` | اجرای Express و Vite در حالت توسعه |
| `npm run lint` | بررسی TypeScript با `tsc --noEmit` |
| `npm run build` | ساخت فرانت‌اند و سرور Node در پوشهٔ `dist` |
| `npm start` | اجرای سرور ساخته‌شده؛ برای حالت تولید، `NODE_ENV` را روی `production` بگذارید |

در صورت نیاز، `.env.example` را به `.env` کپی کنید. `PORT` برای پورت سرور و `APP_URL` برای آدرس عمومی مستند شده است. برای ثبت آمار روی Cloudflare Pages، اتصال اختیاری KV با نام `PIMX_VISITS` وجود دارد.

اجرای پورتفولیو کلید API هوش مصنوعی نمی‌خواهد. endpoint پرامپت سرور Node از قالب محلی استفاده می‌کند. فرم تماس با `mailto:` برنامهٔ ایمیل بازدیدکننده را باز می‌کند؛ سرور ایمیل ارسال نمی‌کند.

## انتشار

### Cloudflare Pages

تنظیمات در [wrangler.toml](wrangler.toml) و توابع در [functions](functions/) قرار دارند.

1. مخزن را به پروژهٔ Pages متصل کنید.
2. دستور ساخت را `npm run build` و پوشهٔ خروجی را `dist` قرار دهید.
3. نسخهٔ مناسب Node را برای محیط ساخت تنظیم کنید.
4. برای ذخیرهٔ آمار، KV را با نام `PIMX_VISITS` متصل کنید. شناسهٔ فعلی namespace متعلق به این انتشار است؛ برای حساب دیگر تغییرش دهید.

اگر اتصال انتشار خودکار فعال باشد، پوش‌کردن کامیت جدید می‌تواند ساخت و انتشار سایت را آغاز کند.

### میزبانی Node در PowerShell

<div dir="ltr">

```powershell
npm ci
npm run build
$env:NODE_ENV = 'production'
npm start
```

</div>

در Bash، دستور آخر `NODE_ENV=production npm start` است. سرور Express محلی، Pages Functions را شبیه‌سازی نمی‌کند. کمک‌ابزار آمار محلی دادهٔ تخمینی/نمایشی هم دارد؛ ثبت سمت سرور به توابع Pages و KV تنظیم‌شده وابسته است.

## بررسی‌ها

گزارش‌های ذخیره‌شدهٔ مرورگر Chromium شامل این مواردند:

- **۶۰ ترکیب صفحه و زبان در عرض ۳۰۰ پیکسل**، بدون بیرون‌زدگی افقی یا خطای اجرا.
- **۴۰ چیدمان صفحهٔ اصلی** در عرض‌های ۳۹۰، ۷۶۸، ۱۴۴۰ و ۲۵۶۰ پیکسل، در هر ده زبان.
- **۵۴ صفحهٔ ترجمه‌شده**، بدون عبارت ترجمه‌نشده از مجموعهٔ عبارت‌های مورد بررسی.
- ورود پیش از رسیدن JavaScript، رفرش، بارگذاری کند صفحه، جابه‌جایی، انتخاب پروژه، خروج نشانگر، فوکوس کیبورد و کاهش حرکت.

این نتایج، بررسی‌های ثبت‌شده‌اند و تضمین همهٔ دستگاه‌ها نیستند. [یادداشت اعتبارسنجی](docs/VALIDATION.md) جزئیات را توضیح می‌دهد.

برای اجرای مجدد، Python و Playwright را نصب کنید و سرور نسخهٔ ساخته‌شده را اجرا کنید:

<div dir="ltr">

```powershell
python -m pip install playwright
python -m playwright install chromium
$env:PORTFOLIO_TEST_URL = 'http://localhost:3000'
python docs/verify-home-redesign.py
python docs/check-localization.py
$env:TEST_LANGUAGES = 'en,fa,ar,de,fr,it,zh,ru,el,la'
$env:TEST_WIDTHS = '300'
python docs/check-responsive.py
```

</div>

تصاویر و خروجی جدید بررسی مرورگر به‌صورت محلی تولید می‌شوند و وارد گیت نمی‌شوند. گزارش‌های کوچک موجود در مخزن، نتایج ثبت‌شدهٔ بررسی قبلی هستند.
